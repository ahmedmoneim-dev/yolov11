Overview

Most autonomous systems lean on expensive GPUs or the cloud. This project shows that a credit-card-sized computer can see, decide and drive on its own. A camera, a nano-sized neural network and a well-optimised inference engine are enough to react to the road in real time.

Real-time detection

YOLOv11n localises and classifies four traffic-sign classes, with several signs in the same frame.

0.99 mAP

NCNN-optimised

The model is converted and tuned for NCNN's ARM kernels. That gives about 5× the speed of the original PyTorch pipeline.

16.3 FPS

Hybrid navigation

Vision decisions are fused with grayscale-sensor line following, so the robot moves in a stable, predictable way.

AI + sensors

Objectives

  1. Develop an embedded real-time object detection module using YOLOv11.
  2. Optimise YOLOv11 inference performance through NCNN deployment.
  3. Design an autonomous navigation mechanism informed by detection outputs.
  4. Evaluate accuracy, latency and navigation stability.

Scope

  • Embedded autonomous driving system with YOLOv11 real-time detection.
  • NCNN as the primary inference engine on low-power hardware.
  • Camera perception, detection-driven navigation and basic obstacle avoidance.
  • Tested in controlled indoor and semi-outdoor environments.

Methodology

From camera frame to motor command

Each step runs on the Raspberry Pi itself, with nothing sent to another computer.

01

Capture

The Pi Camera streams real-time video frames.

02

Pre-process

Frames are converted from RGB to BGR and resized to 640×480.

03

Detect

YOLOv11n on NCNN localises and classifies signs.

04

Decide

Detections are fused with grayscale lane data.

05

Actuate

Speed and direction are sent to the motor controller.

06

Loop

The cycle repeats until a quit action is triggered.

Training & validation

Near-perfect detection accuracy

YOLOv11n was trained on Google Colab for 60 epochs at 640 px with batch size 16. The dataset is balanced: 800 images annotated in Roboflow across four traffic-sign classes.

v1

PyTorch baseline

Accurate, but only 2.7–3.2 FPS on the Raspberry Pi 5. That is too slow for smooth reactions.

v2

First NCNN export

About 3× faster, but confidence dropped and it sometimes misclassified signs, reading U-Turn as No Entry.

v3

Optimised NCNN Latest

16.3 FPS with 0.92–0.94 confidence on all four signs and very little confusion between classes. This is now the production pipeline.

Status

  • Working prototype built
  • Real-time system achieved (16.3 FPS)
  • Tested indoors and semi-outdoors
  • Ready for real-world deployment
Delimitations of the study
  • No GPS, LiDAR, radar or multi-sensor fusion.
  • High-speed vehicle dynamics and full-scale automotive deployment are out of scope.
  • No cloud processing or external GPU. All inference runs locally.
  • Long-range path planning and SLAM are not implemented.
  • Robustness to rain, night-time driving and harsh terrain is not addressed.
